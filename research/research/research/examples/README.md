# Примеры исследований

Эта папка содержит реальные примеры, которые используются для проверки гипотез проекта «Маяк».

Каждый пример должен опираться на проверяемые источники и описывать не мнение, а ход исследования.

Примеры могут как подтверждать гипотезы, так и опровергать их.

Если пример противоречит нашим ожиданиям, это считается ценным результатом исследования.
