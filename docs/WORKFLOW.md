# Рабочий процесс (Workflow)

## Статус документа

**Версия:** 0.1 (Черновик)

---

# Для чего нужен этот документ

Этот документ описывает порядок работы с исследованиями и инструментами проекта «Маяк».

Его цель — сделать процесс исследования понятным и воспроизводимым.

---

# Общая схема

Любое исследование проходит через несколько этапов.

```
Вопрос

↓

Исследование

↓

Инструменты

↓

Вывод

↓

Пересмотр (при необходимости)
```

---

# Этап 1. Постановка вопроса

Сначала формулируется исследовательский вопрос.

Для этого используется:

- QUESTION_METHOD.md

---

# Этап 2. Создание исследования

Если вопрос признан исследовательским, создаётся новое исследование.

Например:

```
research/0004...
```

---

# Этап 3. Проверка исследования инструментами

Исследование не изменяется.

Вместо этого к нему применяются инструменты.

Например:

```
tools/001-hypothesis-check.md
```

Инструменты помогают проверить отдельные части исследования.

---

# Этап 4. Создание примеров использования

Результаты применения инструментов сохраняются отдельно.

Например:

```
tools/examples/
```

В этой папке находятся примеры использования инструментов на реальных исследованиях.

---

# Этап 5. Обновление исследования

Если инструмент выявил слабое место, исследование может быть обновлено.

Изменения обязательно фиксируются.

---

# Главный принцип

Исследование —

не подгоняется под инструмент.

Инструмент —

используется для проверки исследования.

Это позволяет отделить процесс исследования от процесса проверки.
