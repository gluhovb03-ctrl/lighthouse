# Концепция пользовательского интерфейса

## Версия

0.1 (Черновик)

---

# Главная цель

Пользователь не должен читать документацию проекта.

Он должен просто открыть программу и начать исследование.

---

# Главный экран

На первом экране пользователь видит только три действия.

1. Начать новое исследование

2. Открыть существующее исследование

3. Просмотреть библиотеку исследований

---

# Главное правило

Программа должна вести пользователя шаг за шагом.

Она не требует знания методологии.

Она сама задаёт вопросы и объясняет каждый следующий шаг.

---

# Идея

Маяк — это не редактор документов.

Маяк — это мастер проведения исследования.
